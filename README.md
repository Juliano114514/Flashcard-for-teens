# Flashcard for Teens

面向小学英语学习者的离线 Android 词卡应用。应用界面为中文，学习方向固定为看英语选中文。当前版本 **0.1.0 / 6**，默认词库 **5,970 条**，按建议学习学期分为三年级上册至六年级下册，包含主题拓展词汇。

## 学习与词库

- 首页选择八个学期之一，展示所选学期的已学／总词数、百分比及进度条；新学按词条建议归属学期选词，每个学期保存独立日计划。复习、续学、收藏及错题练习跨学期汇总。
- 保留五词交错练习、连续正确轮次、复习排期、答错重学、继续复习、收藏、skip、成长等级及手动下一步。学习音效可独立开关，答案保存成功后先播放短提示音，再进行反馈朗读。
- 题干显示英语词头和 CSV 英式 IPA，选项显示中文并固定一行一条。先选择答案，再点“检查答案”；选“我还不会”也需要检查。初学、答后及详情固定展示英中例句；作答前只显示英语。分步内容默认显示英语分段、中文分段及完整译文，无展开按钮；首次学习集中在一个讲解页，答后反馈点下一步直接继续，不再重复讲解。进入讲解页和答对后的继续页默认依次朗读英语单词、中文释义、当前展示的例句及中文译文，四项共用朗读设置中的独立开关；单词手动朗读偏好仍独立保留。
- 词库支持英文／中文搜索、学期多选及学习状态筛选。三至六年级使用不同的全局主题色，上下册一致，配套深浅模式；渐变背景、半透明卡片和留白保持画面清晰，大字号或窄屏首页入口自动单列排列。
- 中文拼音用于发音，不作为英文音标，也不默认显示。已移除汉字书写、笔顺、部件拆解及语言方向选择。
- Settings 保留每日词量、轮次、复习间隔、朗读偏好、预加载、缓存和新版 CSV 导入。修改设置不重算已开始的学习周期。

## 数据与语音

根目录 `wordlist.csv` 是英语词库维护入口。采用 12 列契约；英文词头大小写和标点有区分，词条 ID 保持稳定。默认库由 Gradle 原字节复制并生成 SHA-256 版本与记录数。2026-10-20 已完成 AI 全量内容复核、重新分级及纯语气词替换；逐条修正与分级记录见 [词库复核记录](docs/wordlist-review.json)。CSV 导入先预览、再在事务内确认追加，详见 [CSV 格式与导入](docs/CSV_IMPORT.md)。

英语使用现有 Kitten Nano INT8／Bella 声线及美式发音前处理；显示音标取自 CSV 的英式 IPA，不据此宣称音频为英式。中文保留 Melo FP32，使用释义、译文和语块各自的拼音。混排文字及不支持读音沿用系统已安装的离线语音兜底；缺少语音不阻塞学习。音频共用预加载协调器与有界持久缓存。

## 工程

应用 ID 与 Kotlin 包前缀为 `com.example.flashcardforteens`；数据库为 `flashcard-for-teens-v1.db`、Room schema v2，从本应用 schema v1 保留学习记录升级；不迁移、读取或删除旧中文应用的数据。

模块保留 app、core/domain、core/data、core/ui、core/media、feature/study、feature/profile、feature/wordlist。继续使用 Kotlin、Compose、Repository／Flow、MVI 及轻量 MVVM，不新增 Android 运行依赖。应用不声明联网或录音权限，关闭备份；[隐私说明](PRIVACY.md) 保留数据边界。

维护入口：[开发说明](docs/DEVELOPMENT.md)、[语音资源](docs/ENGLISH_SPEECH.md)、[中文语音](docs/MELO_TTS_EVALUATION.md)、[CI 与发布](docs/CI_RELEASE.md)、[版本日志](VERSIONLOG.md)。
