# CSV 格式与导入

当前契约仅面向英语词库，恰好 12 列：

`年级,英语词条,音标,词条ID,中文释义,中文释义拼音,词性,例句JSON,干扰词ID,教材来源JSON,发音说明,来源说明`

UTF-8（可带 BOM），支持 CSV 引号转义、CRLF 及引号内换行。沿用 32 MiB 文件、20,000 条记录及字段／JSON 深度限额；旧中文格式和无拼音的旧 11 列不兼容。

- 年级为 `3.0,3.5,4.0,4.5,5.0,5.5,6.0,6.5` 之一，对应三上至六下。它是按词义、使用场景和句型先修评估的建议学习学期，包含拓展内容；不等同教材收录或课标必背。来源 JSON 的 grade 保留原出处年级，允许与当前归属不同。存储使用稳定整数 0–7，避免浮点比较。
- 英语词条与 ID 保留大小写和标点。身份仅进行 NFC 与首尾空白处理；搜索可以不区分大小写，不能据此合并身份。
- 音标来自 CSV，允许多个读音；发音说明可为空。词条 ID 和三个干扰词 ID 直接用于四选一，不派生旧 meaning ID。
- 中文释义及其拼音分别存储；词性、教材来源、发音说明和来源说明均保留。

例句为非空数组，数量不固定为两条：

```json
[{"english":"I like your blue bag.","literalChinese":"我 | 喜欢 | 你的蓝色书包。","chinese":"我喜欢你的蓝色书包。","chinesePinyin":"wǒ xǐ huān nǐ de lán sè shū bāo。","chunks":[{"english":"I","chinese":"我","chinesePinyin":"wǒ"},{"english":"like","chinese":"喜欢","chinesePinyin":"xǐ huān"},{"english":"your blue bag.","chinese":"你的蓝色书包。","chinesePinyin":"nǐ de lán sè shū bāo。"}]}]
```

例句允许可选 `wordIpa`；同形多义词存在名动词异读时，保留词条的多个音标，并由各例句标注相应读音。英文语块按空格拼回 english，中文语块按 ` | ` 拼回 literalChinese。每块须与对应英文表达同一含义；不能把自然中文按长度硬切后配给英语。无法可靠拆分的句子可保留一个完整意义块。chinese 为流畅中文，其语序和拼音无需等于直译语块拼接。

拼音使用带调字符、音节间空格，轻声不标调，保留 ü 和原标点。混排英文／数字保留，不删除注释或伪造为汉语音节。中文整句播放绑定自身拼音；教学语块仅用于逐块播放，不能作为自然译文的发音分块。

教材来源 JSON 保留 grade、file、line、page、section、module、original、chinese、starred 等原始元数据，line 为整数、starred 为布尔。拓展条目可使用空 file 与 line=0，不伪造教材定位。

## 导入行为

设置页选取文件后先校验并预览，确认时复核快照与现有词库，再在同一 Room 事务中追加。错误、取消或失效预览不会提交部分词库。重复词条沿用追加去重语义；同一 ID 对应不同英文身份为冲突，不能覆盖学习记录。

默认词库使用打包字节 SHA-256 和记录数识别版本；完整写入后才提交成功标志。导入不因浏览而创建学习进度，既有学习周期与已保存题卡受到保护。
