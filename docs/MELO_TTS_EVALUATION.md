# 中文播放维护

Flashcard for Teens 保留原有 Melo FP32 单声线、时长输出派生模型、ONNX 推理、弱音处理、统一缓存及系统离线语音兜底。模型及依赖仍按 tools/melo_resources 的固定来源锁核验；模型缓存不提交，应用运行不下载。

新 CSV 提供中文释义拼音、每条例句的 chinesePinyin 及中文语块 chinesePinyin。构建期复用锁定 pypinyin 0.55.0、jieba 0.42.1，不全局安装，不新增 Android 依赖。拼音按上下文生成并复核多音字；一、不和三声由既有前端处理，避免重复变调。

自然译文使用自己的完整中文与拼音，不传英文顺序的直译语块。每个中文语块只绑定自己的拼音；不得要求这些语块拼回流畅译文。

原文中的字母、数字、T恤、DVD、维生素C等保留。现有 Melo 汉语前端不支持的混排整条沿用设备离线普通话兜底，不删除原文、不播放部分内容。缺少可用离线语音时提示，学习仍可继续。前端支持与回退清单由资源检查记录，不能因增加拼音就声称内置模型覆盖全部文本。

模型仍以 `chinese-speech/model-duration.onnx` 保持不压缩，通过 openFd 映射。准备、重建与检查入口见 `python tools/build_chinese_resources.py --help`；`--check` 为只读检查。

本次未更换声线；构建与转换覆盖检查不替代新语料逐条试听或设备延迟、音量、自然度验收。旧中文应用的历史试听结果不作为本版新语料认证。
